# 实验五：技能加载与管理系统

## 一、实验目的

1. 理解技能（Skill）概念及其在AI助手系统中的作用
2. 掌握技能文件的结构化定义方法
3. 实现技能的动态加载和内容解析机制
4. 构建技能调用的完整工作流程

## 二、实验内容

### 2.1 功能概述

本实验实现了一个技能加载与管理系统，支持从指定目录动态加载技能定义文件，并在需要时调用相应技能完成任务。

### 2.2 技能文件结构

技能文件采用Markdown格式，包含YAML头部元数据和技能正文两部分：

```markdown
---
name: notice
description: 用于撰写各类通知文案
---

技能正文内容...
```

### 2.3 核心函数实现

#### 2.3.1 技能列表获取

`list_available_skills()`函数遍历`.agents/skills`目录：
1. 检查每个子目录是否存在`SKILL.md`文件
2. 解析YAML头部提取技能名称和描述
3. 返回可用技能列表

#### 2.3.2 技能内容加载

`load_skill_content(skill_name)`函数：
1. 根据技能名称定位技能目录
2. 读取`SKILL.md`文件内容
3. 提取YAML头部之后的技能正文
4. 返回技能内容供后续使用

#### 2.3.3 系统提示词生成

`get_skills_system_prompt()`函数构建技能调用提示：
- 列出所有可用技能及其描述
- 定义技能调用流程：加载规则→执行任务→生成结果
- 明确无需强行调用技能的条件

### 2.4 技能调用流程

完整的技能调用工作流程如下：

```
用户请求 → 技能匹配 → load_skill_content() → 执行任务 → 返回结果
    ↓                              ↓
  分析需求                     获取技能规则
```

### 2.5 技能触发机制

当用户请求需要使用特定技能时，系统自动执行以下步骤：
1. LLM分析用户请求，识别所需技能
2. 调用`load_skill_content`工具获取技能详细规则
3. 根据规则执行相应任务
4. 生成最终结果并返回给用户

## 四、实验总结

### 4.1 技术要点

1. **模块化设计**：技能以独立文件形式存储，便于扩展和维护
2. **元数据管理**：通过YAML头部统一管理技能元信息
3. **动态加载**：运行时按需加载技能，提高系统灵活性

### 4.2 功能扩展

本实验在practice04基础上新增了技能系统，具备以下能力：
- 自动发现和加载可用技能
- 根据用户需求智能选择技能
- 按照技能规则执行特定任务

### 4.3 应用场景

技能系统适用于以下场景：
- 模板化内容生成（通知、报告、邮件等）
- 特定领域任务处理（数据分析、文档生成等）
- 工作流程自动化

### 4.4 改进方向

1. 增加技能版本管理，支持技能更新
2. 实现技能依赖关系管理
3. 添加技能使用统计和性能监控
