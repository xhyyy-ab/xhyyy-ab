# LLM工具调用扩展实验报告

## 实验目的

本实验旨在扩展LLM客户端功能，实现工具调用能力，使AI助手能够执行实际操作任务。具体目标包括：

1. 理解工具调用的核心概念与实现原理
2. 实现文件系统操作工具（增删改查）
3. 实现网络访问工具（HTTP请求）
4. 掌握工具调用的完整流程与协议规范

## 实验内容

### 1. 工具定义与配置

实现了工具配置系统`get_tools_config()`，定义以下工具：

| 工具名称 | 功能描述 | 参数 |
|---------|---------|------|
| `list_directory` | 列出目录文件列表 | `dir_path` |
| `rename_file` | 重命名文件 | `dir_path`, `old_name`, `new_name` |
| `delete_file` | 删除文件 | `dir_path`, `file_name` |
| `create_file` | 创建文件并写入内容 | `dir_path`, `file_name`, `content` |
| `read_file` | 读取文件内容 | `dir_path`, `file_name` |
| `curl` | HTTP/HTTPS网页访问 | `url` |

工具配置遵循OpenAI工具调用规范，包含`type`、`function.name`、`function.description`和`function.parameters`字段。

### 2. 文件系统操作工具

**目录列表功能**：
- 使用`os.listdir()`遍历目录
- 获取文件大小、修改时间等属性
- 支持大小单位自动转换（字节/KB/MB）
- 输出JSON格式结果

**文件操作功能**：
- 创建文件：检查文件是否已存在，写入UTF-8编码内容
- 读取文件：验证文件路径有效性
- 重命名文件：检查源文件和目标文件状态
- 删除文件：验证文件存在性

### 3. 网络访问工具

**curl工具实现**：
- 支持HTTP和HTTPS协议
- 自动处理URL编码
- 针对`wttr.in`提供特殊支持，获取天气预报
- 同时返回ASCII图形和JSON详细数据

**天气预报增强功能**：
- 获取今日和明日天气信息
- 解析最高气温、最低气温、平均气温
- 获取天气描述信息

### 4. 工具调用流程

实现完整的工具调用闭环：

```
用户输入 → 调用LLM → 解析tool_calls → 执行工具 → 获取结果 → 总结回答
```

**关键步骤**：
1. 在请求中携带`tools`和`tool_choice`参数
2. 解析LLM响应中的`tool_calls`字段
3. 根据工具名称调用对应函数
4. 将工具执行结果追加到对话历史
5. 再次调用LLM进行结果总结

## 实验总结

### 技术要点

1. **工具定义规范**：采用OpenAI工具调用格式，确保兼容性
2. **参数验证机制**：每个工具实现输入验证和错误处理
3. **流式与非流式结合**：流式响应用于普通对话，非流式响应用于工具调用解析
4. **对话历史管理**：维护完整的对话上下文，支持多轮工具调用

### 学习收获

通过本实验，掌握了以下核心技能：

- LLM工具调用的协议规范和实现方法
- 文件系统操作的Python实现
- HTTP客户端开发与响应处理
- 工具调用的完整流程设计
- 错误处理与异常捕获机制

### 改进方向

1. 增加工具权限控制，限制危险操作
2. 实现工具调用的事务管理，支持回滚
3. 添加工具执行超时控制
4. 支持异步工具调用，提高并发性能
