## 1. 测试概述

### 1.1 测试目标

验证 SkinCheck 皮肤病智能自查小程序在功能、性能、安全、兼容性等维度满足 SPEC 与 SRS 定义的需求规格，确保产品质量达到上线标准。

### 1.2 测试范围

| 测试维度 | 覆盖范围 | 优先级 |
|---------|---------|--------|
| 功能测试 | 全部 17 个功能需求 (FR-AUTH-001 ~ FR-USER-004) | P0 |
| 接口测试 | 全部 13 个 API 接口 | P0 |
| 性能测试 | 启动时间、识别耗时、并发承载 | P1 |
| 安全测试 | 越权访问、数据加密、输入安全 | P0 |
| 兼容性测试 | 微信版本、操作系统、屏幕适配 | P1 |
| 用户体验测试 | 交互流程、异常提示、弱网降级 | P1 |

### 1.3 测试通过标准

| 标准项 | 要求 |
|--------|------|
| 功能测试 | P0 用例 100% 通过，P1 用例 ≥ 95% 通过 |
| 接口测试 | 全部接口返回符合 API 文档规范 |
| 性能测试 | 所有性能指标达到 NFR 定义规格 |
| 安全测试 | 无高危/严重级别安全漏洞 |
| 缺陷密度 | 遗留缺陷 ≤ 5 个，且均为轻微/建议级别 |

        expect(result.primary.diseaseName).toBe('湿疹');
        expect(result.alternatives).toHaveLength(0);
        expect(result.urgencyLevel).toBe('medium');
    });

    test('中置信度多候选', () => {
        const aiResult = {
            predictions: [
                { diseaseId: 'd1', diseaseName: '湿疹', confidence: 0.72 },
                { diseaseId: 'd2', diseaseName: '接触性皮炎', confidence: 0.58 },
                { diseaseId: 'd3', diseaseName: '荨麻疹', confidence: 0.15 }
            ]
        };

        expect(result.primary.confidence).toBe(0.72);
        expect(result.alternatives).toHaveLength(1);
        expect(result.alternatives[0].confidence).toBe(0.58);
    });

            ]
        };

        expect(result.urgencyLevel).toBe('high');
    });

    });
