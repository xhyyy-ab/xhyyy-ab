# 主题锚定规范 (Topic Anchoring)

## 1.1 核心主题声明
- **主命题**：作为大二软件工程学生，如何在技术学习与人生成长的双重挑战中，以稻盛和夫"持续努力、心性打磨"的哲学找到平衡与方向
- **边界范围**：
  - 必须涵盖：
    1. 技术学习层面：课程学习、代码编程、项目实训中的具体困惑与方法
    2. 成长困境层面：就业与考研的迷茫、社团团队协作中的摩擦
    3. 精神内核层面：人生态度、坚持努力、脚踏实地、拒绝浮躁、心怀梦想、逆境成长
    4. 身份共鸣层面：必须时刻锚定"大二软件工程学生"这一真实身份
  - 明确排除：
    - 不讨论稻盛和夫的具体企业经营案例（如日航重建细节）
    - 不泛泛而谈"梦想的重要性"这类空洞主题
    - 不写成品德教育心得或思想政治汇报
- **目标读者**：同为软件工程专业的大学生、面临相似困惑的在校学生

## 1.2 偏题检测机制
生成过程中，每完成一个章节需自检：
- [ ] 本节内容是否直接支撑主命题？即：是否在谈"作为软件工程学生"应用稻盛和夫思想？
- [ ] 本节是否引入了与"大二软件工程学生"身份无关的内容？
- [ ] 本节是否在讲道理而非结合真实经历？
- [ ] 若删除本节，"技术学习+人生成长"的双重主线是否仍然完整？

## 1.3 题材适配示例
| 题材类型 | 主命题示例 | 边界排除示例 |
|---------|-----------|------------|
| 软件工程报告 | 本系统如何通过微服务架构解决高并发场景下的性能瓶颈 | 不讨论前端UI设计细节、不对比其他公司商业产品 |
| 读书心得 | 《你的梦想一定能实现》中"持续努力"哲学对软件工程专业学生学业困境的启示 | 不介绍作者生平年表、不讨论该书出版市场反响 |
| 入党申请书 | 个人在思想/实践/学习三维度向党组织靠拢的历程与决心 | 不罗列所有获奖证书、不抱怨社会负面现象 |

## 1.4 纠偏触发词
当内容偏离时，使用以下句式强制回归：
- "回到核心命题：作为大二软件工程学生，我们需要聚焦于..."
- "具体到我的身份——一名软件工程专业的学生，这意味着..."
- "回到技术学习和成长这两个维度..."

## 1.5 主题深化要点
- 每次提到稻盛和夫的思想时，必须追问："这对一个天天写代码的大学生意味着什么？"
- 每次讲述个人经历时，必须追问："我学到了什么可迁移的方法论？"
- 始终保持"技术思维"与"人生哲学"的交织感
